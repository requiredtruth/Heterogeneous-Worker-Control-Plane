# Support development

Donations fund additional development time and increase production. A confirmed donor may open the funded-direction issue template with the asset, exact network, public transaction hash, and the specific feature, test, documentation area, or project direction they want expanded.

The first GitHub issue claiming an unclaimed confirmed inbound transaction hash receives operational request attribution for that transaction. This is not cryptographic proof of wallet ownership, and an already attributed hash cannot be reused. A donation does not purchase ownership, investment returns, a delivery deadline, guaranteed delivery, or acceptance of unsafe, illegal, private, proprietary, or out-of-scope work.

Confirm the asset, address, network, and wallet compatibility before sending. Transactions cannot be reversed.
